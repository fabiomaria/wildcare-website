## Current CMS/content model

Sveltia CMS lives in:

- `admin/index.html`
- `admin/config.yml`
- `admin/sveltia-cms-0.171.1.js`

Global content:

- `content/site.yaml`

Page content:

- `content/pages/index.yaml`
- `content/pages/kontakt.yaml`
- `content/pages/team.yaml`
- `content/pages/journal.yaml`
- `content/pages/programm.yaml`

Journal:

- `content/journal/*.md`
- German default files: `slug.md`
- English files: `slug.en.md`
- Journal supports `de_only`, `en_only`, and `bilingual`.
- Phase-0 files named `phase0-*` are deliberately ignored by the Eleventy journal loader.

Workshops:

- `content/workshops/*.yaml`
- Editors enter only `slug`; the build derives `<slug>.html`.
- Programme cards render from workshop entries with `status: upcoming` or `status: current`.
- Card-only workshop entries appear on `programm.html`.
- Detail links appear only when detail-page content is complete enough to build a detail page.
- Current detail pages support German-only or English-only. Full bilingual workshop detail-page switching is not built yet.
- `content/workshops/test.yaml` is a user-created uncommitted test workshop. It appears on the local programme page as a card but has no detail link because detail fields are incomplete.

## Validation commands

Build:

```bash
npm run build
```

Normalized diffs for migrated pages:

```bash
scripts/normdiff.sh index.html
scripts/normdiff.sh kontakt.html
scripts/normdiff.sh team.html
scripts/normdiff.sh journal.html
scripts/normdiff.sh programm.html
scripts/normdiff.sh cellular-touch.html
```

Article pages intentionally differ structurally from the original raw HTML because journal bodies moved from per-element `data-de`/`data-en` attributes to per-locale Markdown blocks:

```bash
scripts/normdiff.sh journal/warum-ci.html
scripts/normdiff.sh journal/bewegungsrevolution.html
```

Local preview:

```bash
npx eleventy --serve --port=8083
```

Then open:

```text
http://localhost:8083/programm.html
http://localhost:8083/admin/
```

If the sandbox blocks the listener with `EPERM`, rerun the same command with tool escalation/approval.

## Useful implementation notes

- `scripts/normdiff.sh` normalizes entities, repairs pre-existing unquoted `href=https://...` during comparison, formats with Prettier, and drops blank-only lines. It is an acceptance helper, not production code.
- `eleventy.config.js` contains custom loaders for journal and workshop content.
- `site/_includes/partials/nav.njk` and `footer.njk` support `pathPrefix` for nested pages.
- `site/_includes/partials/icon.njk` contains the inline SVG icons used by programme/workshop templates.
- `js/i18n.js` now includes additive support for `[data-journal-lang]` Markdown body blocks.
- `css/styles.css` has not been edited and should remain untouched.
