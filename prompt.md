## Useful Implementation Notes

- `scripts/normdiff.sh` normalizes entities, repairs pre-existing unquoted `href=https://...` during comparison, formats with Prettier, and drops blank-only lines. It is an acceptance helper, not production code.
- `eleventy.config.js` contains custom loaders for journal, workshops, and legal content.
- `site/_includes/partials/nav.njk` and `footer.njk` support `pathPrefix` for nested pages.
- `site/_includes/partials/icon.njk` contains inline SVG icons used by programme/workshop templates.
- `js/i18n.js` includes additive support for `[data-journal-lang]` Markdown body blocks.
- Legal markdown has two render modes:
  - `body_html` for pages that wrap the whole prose block once.
  - `body_html_fadeup` for pages whose original markup had `class="fade-up"` on each child.
- `css/styles.css` has not been edited and should remain untouched.
